Expertimental feature

Additional credentials to use when the primary credentials reach the API usage limit.

The selected credentials must be of the same type, otherwise a runtime error will be generated. Each credential is used when the previous one reaches the API usage limit.

If one of the selected credentials expires (for example, the API token), the client will generate an authentication error and no attempt will be made to use other credentials. The goal of this feature is to use backup credentials when one reaches its API usage limit, ensuring that all credentials are valid and not expired.
